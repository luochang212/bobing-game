## Critical（违反"脚本镜像纸面"契约）

### C1. 加赛状态机：挑战者掷出「未超越的状元」不消耗挑战窗口

**位置**：`scripts/champion_final.py:40-47`（`do_roll` 的 `cat == 'Z'` 分支）对照 `champion-final/rules-paper.tex:78`

**纸面**：

> 领先成绩产生后，从其下一位起，**其他每位参赛者各掷一次**而无人超越时，领先者当选状元王，加赛结束。

**代码**：`cat == 'Z'` 时直接 `return 'z'`，挑战窗口递减只在非状元分支（`champion_final.py:49-52`）发生。挑战者掷出状元但未超越现任时，这一掷不计入"各掷一次"。

**实测复现**（3 人桌）：

```
0 号四红带12 领先；1 号掷四红带5（状元、未超越）；2 号无奖。
纸面读法：其余二人各掷一次、无人超越 → 3 掷封盘。
实际脚本：5 掷才封盘（end=sealed, winner=0, n_rolls=5）。
```

**影响**：不只是拖长比赛——纸面上此时加赛已经结束，而模型里 1 号下一轮还有机会反超获胜，**可以改变胜者**。脚本自身 docstring（"领先确立后其他每人各掷一次"）与 AGENTS.md（"被其他每人各挑战一次"）均与纸面一致，唯独代码不一致；且 M3 剧本名字写着"挑战掷数照常消耗"（`champion_final.py:110`），但断言未钉 `n_rolls`，该性质从未被测到。与 rule-audit 已修复的 `sum_phase_mode` 镜像偏差（K5 事件）同类。

**修法建议**：Z 分支中未取代领先时，走与非状元掷相同的窗口递减与封盘判断（`seat != leader[3]` 守卫天然覆盖"领先者本人掷出更差状元"的情况），并加一个钉住 `n_rolls` 的剧本（如 M8）。

### C2. state_machine.py G2/G3 剧本不具区分力，且 G2 名字与规则相反

**位置**：`scripts/state_machine.py:208-217`

**问题**：

1. G2 喂 `444411`（插金花）给 `players=1` 的游戏，现任领先者就是 0 号位本人——无论插金花是否取代六红，`g['leader'][3]` 都是 0，**断言恒真**。G3（六同 vs 六红）同理。
2. G2 名字"**六红胜插金花**"与规则纸直接矛盾：`versions/*/rules-paper.tex` 第三节明确"状元插金花……**本场最高**"，`ZY_RANK`（`state_machine.py:53`）也是插金花=6 > 六红=5。G 组注释（208 行）内部自相矛盾——G1 说"插金花最高"，G2 说"六红胜插金花"，疑为当年修订排序时只改了 G1 忘了 G2。

**破坏性实验**：把 `ZY_RANK` 里插金花与六红的等级对调（直接违背纸面"插金花最高"），**20 项 tiered 剧本依然全部通过**。

**影响**：插金花压过六红恰是本稿相对传统排序（维基版为全红最高）最反常识、最依赖"本场约定"辩护的一处选择——偏偏是全测试套件唯一没钉住的地方。将来任何人动 `ZY_RANK` 都会静默通过 CI 而破坏规则纸。

**修法建议**：G2/G3 把现任领先者放到别的座位（`players=2`）或断言 `leader[0]`；G2 名字改成与规则一致（如"插金花胜六红"）。

- **判定逻辑逐条核对通过**：奖级六档、状元六等级的条件、"从上往下只认最高奖级"、不兼奖不降档、补轮/加赛/比总和三段式结束——tex 文字与 `classify()` 实现语义一致，46656 全枚举保证归类无重叠无遗漏。四红"比另 2 颗之和"、五红/五子"只比剩余 1 颗"、六同"彼此同级"等易错点均有对应剧本。
