# classic —— 标准 63 份

本次活动的基准版本：每桌固定 63 份奖品（状元 1、对堂 2、三红 4、四进 8、二举 16、一秀 32），
单桌多桌通用（多桌时各桌独立、各出一个状元），无全场环节。

规则族：fixed63（与 grand-final 同族，共享段逐行比对）
特征句：各地博饼习俗略有不同，本次活动统一以上述规则为准

- **依据**：全部修订记录见 [docs/rule-audit.md](../../docs/rule-audit.md)
- **切换**：把仓库根目录 `current` 文件改成本目录名，`make pdf` 重编译后提交；
  网站随 site 工作流重新部署。

特征句供 CI 校验"指针与产物一致"：交付 PDF 必须包含本句，否则说明改了
`current` 却没有重编译提交。
