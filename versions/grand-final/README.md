# grand-final —— 王中王

多桌并开且要决出全场冠军的场景：各桌独立博饼（规则与 classic 完全一致，各桌产生
自己的状元），桌状元最后集中加赛，决出全场唯一的"状元王"。加赛直接复用规则纸
第三节的状元比较体系，重新掷骰当场比，不比历史骰面；决赛时间、地点等安排属活动
流程，由主办方确定后放在讲解页，纸上只留"安排见扫码页"的钩子。

- **特征句**：博出的状元晋级全场
- **依据**：桌内规则与 classic 相同，见 [docs/rule-audit.md](../../docs/rule-audit.md)；
  全场加赛环节的现实依据（厦门"状元王中王"大赛、金门 538 桌总决赛等）见
  rule-audit.md 的"多版本与全场加赛"一节
- **切换**：把仓库根目录 `current` 文件改成本目录名，`make pdf` 重编译后提交；
  网站随 site 工作流重新部署。

与 classic 的全部差异只有两处：源稿头注（本行说明）与底部小字行（钩子句替换
classic 的"各地习俗"句），由 `scripts/version_consistency.py` 保证共享段落一致。
