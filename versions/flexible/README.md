# flexible —— 灵活奖品

奖品总数与分档数量不固定的场景（主办方有多少放多少，"有多少个拿多少个"），
单桌多桌通用，无全场环节。与 classic 的规则差异只有奖品模型一处：

- 页头改为"奖品若干份，先留 1 份作状元奖"，纸上不标注任何数量；
- 奖级表去掉"份数"列，六档判定条件逐字不变；
- 不兼奖句不再提"降档"（没有分档库存，无档可降），掷中普通奖领 1 份；
- 结束触发从"62 份普通奖发完"改为"奖品领到只剩状元奖时"；
- 判定条件、状元比较体系、异常处理、收尾骨架（补轮＋加赛＋比总和）与
  记录栏逐字不变。

规则族：pooled（跨族只锁定共有的判定与状元段落，由 `scripts/version_consistency.py` 按族比对）
特征句：奖品领到只剩状元奖
排除句：博出的状元晋级全场

特征句与排除句共同保证 CI 的"指针与产物一致"检查无歧义：本版与
flexible-grand-final 只差底注钩子，须靠"不含晋级全场"区分。

- **依据**：奖品模型的取舍与状态机扩展记录见 [docs/rule-audit.md](../../docs/rule-audit.md)
- **切换**：把仓库根目录 `current` 文件改成本目录名，`make pdf` 重编译后提交；
  网站随 site 工作流重新部署。
