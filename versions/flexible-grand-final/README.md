# flexible-grand-final —— 灵活奖品 · 王中王

多桌并开、要决出全场冠军、且奖品总数不固定的场景：奖品若干（先留 1 份作
状元奖，"有多少个拿多少个"），各桌独立博饼，各桌状元最后集中加赛决出全场
"状元王"。

与 flexible 的差异只有底注钩子句（桌内规则逐字相同）；与 grand-final 的
差异只有奖品模型（决赛机制相同，直接复用规则纸第三节的状元比较体系，重新
掷骰当场比）。取舍与依据见 [docs/rule-audit.md](../../docs/rule-audit.md)。

规则族：pooled（与 flexible 同族，共享段逐行比对；跨族与 fixed63 只锁共识块）
特征句：奖品领到只剩状元奖
特征句：博出的状元晋级全场

特征句可多行，交付 PDF 必须全部包含；另可在 README 声明"排除句：……"，
表示交付 PDF 不得包含该句（用于区分只差底注钩子的版本）。两者共同保证
CI 的"指针与产物一致"检查在各版本之间无歧义。

- **切换**：把仓库根目录 `current` 文件改成本目录名，`make pdf` 重编译后提交；
  网站随 site 工作流重新部署。
