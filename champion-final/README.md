# champion-final —— 状元王加赛纸

多桌活动压轴的独立一张纸：各桌状元同台轮掷，按状元比较体系决出全场唯一的
"状元王"。桌内规则纸不出现状元王内容——每张纸只服务自己那张桌子；本纸
只服务决赛桌，主办方按参加桌数另印数份即可。奖品模型（63 份或若干份）与
本纸无关，一张通用于两个桌内版本。

- **特征句**：状元王加赛
- **停止条件**（本纸成文；公开赛事普遍未成文）：领先成绩被其他每人各挑战
  一次而无人超越即封盘；连续 10 轮无状元则每人加掷、一掷两用、比总和兜底。
  收敛依据与对赛事先例的两处偏离见 [docs/rule-audit.md](../../docs/rule-audit.md)。
- **机器校验**：`python3 scripts/champion_final.py`（封盘、兜底、一掷两用、
  同和再掷全部有剧本与随机模拟）；状元等级表与各桌规则纸第三节由
  `scripts/version_consistency.py` 跨件比对。
- **编译**：`make pdf-final`，产物 `output/pdf/champion-final.pdf`。
